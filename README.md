# Firecrawl Dashboard — public documentation

Public portfolio documentation for a protected self-hosted Firecrawl control plane.

- [English documentation](https://nick-nalivaiko.github.io/firecrawl-dashboard-docs/en/)
- [Русская документация](https://nick-nalivaiko.github.io/firecrawl-dashboard-docs/ru/)
