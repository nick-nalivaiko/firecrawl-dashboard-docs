Architecture

Custom platform features stay isolated from upstream.

Authentication, projects, gateway policy, usage, and operational storage live in a dedicated platform layer. Firecrawl Core remains a separate pinned component, while upstream Dashboard updates are reviewed through reproducible Git upgrade branches.

DashboardOwner workflows, project controls, reporting, and configuration.
Managed gatewayProject authentication, limits, policy, accounting, and safe routing.
Firecrawl CoreVersioned collection engine with independently verified readiness.
Operational dataPostgreSQL metadata and short-lived artifacts with explicit retention.
